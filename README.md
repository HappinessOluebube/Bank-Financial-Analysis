Overview
The Bank Database Analysis project uses SQL to analyze customer information, account balances, and transaction activities to generate insights that support financial reporting and business decisions.

Key Insights
1. Customer Distribution: Identifies locations with the highest number of customers.
2. Account Performance: Compares balances across savings, current, and fixed deposit accounts.
3. Transaction Trends: Reveals popular transaction channels and monthly transaction activity.
4. Transaction Monitoring: Identifies failed and reversed transactions requiring investigation.
   
Recommendations
1. Expand Customer Reach: Target locations with lower customer numbers for growth opportunities.
2. Improve Account Services: Develop strategies to attract more deposits and strengthen account engagement.
3. Enhance Digital Banking: Improve popular transaction channels and encourage convenient digital services.
4. Strengthen Monitoring: Investigate failed and reversed transactions to improve service reliability and customer trust.
